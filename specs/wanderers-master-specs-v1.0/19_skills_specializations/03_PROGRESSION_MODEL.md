# Skill Progression Model v1.0

Avoid pure XP grinding. Skill growth can come from meaningful use, relevant objectives, discoveries, training, specialized equipment, and consequential decisions.

### 0 — Untrained
Basic actions only.

### 1 — Familiar
Simple assisted actions.

### 2 — Competent
Reliable standard actions.

### 3 — Specialist
Alternative solutions become available.

### 4 — Expert
Complex/systemic solutions become available.

### 5 — Signature
Unique high-level approaches and special interactions.

No permanent class lock. Build = skills + specialization + equipment + faction privileges + knowledge + behavior.
