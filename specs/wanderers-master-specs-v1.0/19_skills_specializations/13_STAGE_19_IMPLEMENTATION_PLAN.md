# Stage 19 Implementation Plan

## Phase 1 — Contracts
Create/align:
- SkillState
- SkillDefinition
- SkillCheck
- SkillOutcome
- Specialization
- SkillSignal

## Phase 2 — Runtime
Connect checks to authoritative scanning, flight, combat support, trade, equipment and mission actions.

## Phase 3 — Narrative
Expose skill-dependent dialogue, evidence, missions, NPC reactions and faction opportunities.

## Phase 4 — Vertical slice
Rework the Convoy/Ferrum chain so the same mystery can be investigated through Sensors, Engineering, Social, Commerce, Covert and Piloting.

## Phase 5 — QA
Measure skill-based approaches, unique information outcomes, equipment interactions, NPC/faction interactions and build diversity.

## Acceptance
- six skill axes;
- gameplay meaning for every axis;
- 3+ skill-based approaches in major missions;
- graded outcomes;
- 4+ distinct builds;
- no skill that is only a percentage modifier.
