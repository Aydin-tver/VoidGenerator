# Specialization Model v1.0

Examples:

Engineering: Reactor Specialist, Salvage Engineer, Systems Analyst.
Sensors: Investigator, Signal Analyst, Anomaly Researcher.
Commerce: Trader, Broker, Logistics Operator.
Social: Negotiator, Mediator, Intelligence Broker.
Piloting: Courier, Interceptor, Convoy Pilot.
Covert: Smuggler, Infiltration Operator, Counter-Detection.

Specialization opens opportunities while making some alternatives relatively weaker. No specialization should be universally best.
