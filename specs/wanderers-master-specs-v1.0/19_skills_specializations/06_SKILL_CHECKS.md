# Skill Checks v1.0

Avoid binary checks.

Use:

skill level + equipment + knowledge + preparation + risk → outcome quality

Outcomes:
- unavailable
- possible but risky
- normal
- strong
- exceptional

Example:
Sensors 1 → incomplete reading.
Sensors 3 → identifies the pattern.
Sensors 5 → identifies the pattern and detects signal manipulation.

Higher skill should reveal different information or options, not simply produce a larger reward.
