# Skill Axes v1.0

Six broad axes keep the system readable on mobile.

## PILOTING
Flight, pursuit, evasion, risky navigation, convoy handling.

## ENGINEERING
Ship systems, reactor, repair, salvage, technical analysis.

## SENSORS
Scanning, anomaly detection, evidence collection, signal analysis.

## COMMERCE
Trade, market analysis, negotiation, logistics.

## SOCIAL / NEGOTIATION
Persuasion, reading motives, mediation, information exchange.

## COVERT / OPERATIONS
Discreet investigation, smuggling, concealment, risk management.

Each axis must create gameplay opportunities outside pure combat statistics.
