# Wanderers of the Void — Dialogue Gameplay System v1.0

## Goal

Dialogue is a gameplay system, not a text-only presentation layer.

A conversation should allow the player to:
- obtain information;
- test information;
- persuade;
- deceive;
- conceal;
- threaten;
- bargain;
- exchange favors;
- create obligations;
- change relationships;
- influence factions;
- create missions;
- alter future world state.

Core loop:

PLAYER INTENT
→ DIALOGUE APPROACH
→ INFORMATION / SOCIAL ACTION
→ NPC RESPONSE
→ MEMORY / RELATIONSHIP CHANGE
→ CONSEQUENCE
→ FUTURE OPPORTUNITY

## Anti-cosmetic rule

A dialogue branch is meaningful only when it can change at least one:
- knowledge;
- NPC state;
- faction state;
- mission state;
- economic state;
- access;
- future dialogue;
- world consequence.
