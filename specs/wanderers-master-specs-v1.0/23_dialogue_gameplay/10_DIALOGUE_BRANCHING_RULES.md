# Dialogue Branching Rules v1.0

Avoid massive exponential dialogue trees.

Use state-driven convergence.

Branches may differ in:
- information acquired;
- relationship;
- obligation;
- faction state;
- evidence;
- available future actions.

Then converge into a shared next situation.

Example:

ASK directly
PROBE indirectly
THREATEN
BRIBE
TRADE evidence

→ different state changes
→ same investigation continues from different conditions.

This keeps content scalable while preserving agency.
