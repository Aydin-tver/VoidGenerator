# NPC Relationships v1.0

Relationships are multi-dimensional.

Do not use:

```text
friendship = 72
```

Use dimensions such as:

- trust;
- respect;
- fear;
- resentment;
- dependence;
- professional respect;
- personal attachment;
- ideological alignment.

Two NPCs can:
- respect each other but distrust each other;
- cooperate while resenting each other;
- depend on each other while competing;
- share a secret while belonging to rival factions.

Player relationships should work the same way.
