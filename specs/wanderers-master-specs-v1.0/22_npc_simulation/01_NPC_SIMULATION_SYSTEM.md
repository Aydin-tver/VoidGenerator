# Wanderers of the Void — NPC Simulation System v1.0

## Goal

Turn important NPCs from dialogue providers into persistent systemic actors.

An NPC has:
- goals;
- needs;
- beliefs;
- memory;
- relationships;
- faction affiliation;
- personal secrets;
- capabilities;
- resources;
- fears;
- loyalties;
- boundaries;
- reactions.

Core loop:

PLAYER ACTION
→ NPC PERCEPTION
→ MEMORY UPDATE
→ EMOTIONAL / TRUST UPDATE
→ GOAL REASSESSMENT
→ NPC ACTION
→ WORLD / PLAYER REACTION

## Anti-cosmetic rule

An NPC should not be considered systemic merely because dialogue changes.

A meaningful NPC state change must be able to affect at least one of:
- information;
- mission availability;
- faction relationships;
- trade;
- station access;
- equipment access;
- consequences;
- future dialogue;
- NPC-generated actions.
