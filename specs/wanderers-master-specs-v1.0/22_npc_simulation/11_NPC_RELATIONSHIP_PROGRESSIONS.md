# NPC Relationship Progressions v1.0

Relationships should evolve through events.

Possible progression:

Unknown
→ Contact
→ Useful acquaintance
→ Trusted contact
→ Ally
→ Close ally

Alternative trajectories:

Contact
→ Distrust
→ Suspicion
→ Rival
→ Enemy

Or:

Contact
→ Dependency
→ Conflict
→ Reconciliation

Do not force every NPC into friendship.

Some NPCs should remain:
- professional contacts;
- uneasy allies;
- ideological opponents;
- useful rivals.
