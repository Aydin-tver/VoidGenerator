# NPC × Faction Integration v1.0

NPCs have both personal and faction interests.

Possible states:

```text
FACTION LOYALTY
vs
PERSONAL GOAL
```

These may align or conflict.

Example:

Tidari registry official:
- officially protects registry integrity;
- personally wants career advancement;
- secretly distrusts the Enforcement Office.

Player can exploit this without changing the official faction relationship.

NPC actions can also feed back into faction state:
- report;
- recommendation;
- accusation;
- leak;
- promotion request;
- resource request.
