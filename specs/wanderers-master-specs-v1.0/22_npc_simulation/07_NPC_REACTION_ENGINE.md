# NPC Reaction Engine v1.0

Inputs:
- player actions;
- memories;
- relationship state;
- current goals;
- faction state;
- information;
- equipment;
- skills;
- world events.

Reaction options:
- ignore;
- acknowledge;
- help;
- ask;
- warn;
- refuse;
- lie;
- bargain;
- retaliate;
- report;
- recruit;
- protect;
- abandon;
- create mission.

Reaction priority should depend on:
1. goal relevance;
2. emotional weight;
3. threat;
4. opportunity;
5. faction pressure;
6. relationship.
