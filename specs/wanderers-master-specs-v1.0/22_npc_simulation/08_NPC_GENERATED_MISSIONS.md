# NPC-Generated Missions v1.0

Important NPCs can create missions from their goals.

Mission origin:

NPC GOAL
+
CURRENT PROBLEM
+
PLAYER RELATIONSHIP
+
AVAILABLE PLAYER CAPABILITIES
=
NPC REQUEST

Examples:

Nova needs:
- evidence protected from OmniCorp.

She may ask:
- transport a sample;
- inspect a wreck;
- verify a signal;
- find a missing engineer;
- keep a discovery secret.

The same NPC can generate different requests after the world changes.
