# NPC World Actions v1.0

Important NPCs should sometimes act without direct player prompting.

Supported actions may include:
- send message;
- request meeting;
- change a station service;
- recommend player;
- report player;
- change faction support;
- relocate;
- close a trade deal;
- start a mission;
- reveal information;
- conceal evidence.

These are not full autonomous simulation.

Use bounded, event-driven NPC actions that are explainable and testable.
