# Faction × NPC Network v1.0

NPCs are the visible interface to faction systems.

NPCs may:
- belong to internal groups;
- have faction loyalty;
- disagree with official policy;
- possess secrets;
- recommend the player;
- report player actions;
- request favors;
- oppose another NPC.

Faction state should not replace NPC memory.

Instead:

FACTION STATE
↕
NPC STATE
↕
PLAYER ACTION

This creates local consequences for global faction changes.
