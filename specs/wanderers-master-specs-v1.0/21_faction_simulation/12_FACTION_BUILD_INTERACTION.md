# Faction × Skills × Equipment v1.0

Faction access should interact with player build.

Examples:

Sensors:
- investigate faction anomalies;
- verify claims.

Engineering:
- repair faction infrastructure;
- evaluate prototypes.

Commerce:
- exploit shortages;
- negotiate contracts.

Social:
- influence internal groups.

Covert:
- acquire protected intelligence.

Piloting:
- perform dangerous logistics or interception.

Equipment can further alter these options.

Thus:

BUILD + EQUIPMENT + FACTION STATE
→ unique gameplay possibilities.
