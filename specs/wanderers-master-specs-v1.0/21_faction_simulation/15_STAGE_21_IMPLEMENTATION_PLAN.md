# Stage 21 Implementation Plan

## Phase 1 — State

Implement:
- FactionState
- FactionRelationship
- FactionRank
- FactionPrivilege
- InternalGroupState
- FactionConflict

## Phase 2 — Reactions

Implement deterministic reaction rules.

## Phase 3 — Integration

Connect:
- missions;
- NPC memory;
- equipment;
- skills;
- economy;
- station services;
- knowledge/evidence.

## Phase 4 — Vertical slice

Implement OmniCorp / Free Merchants route conflict.

## Phase 5 — Simulation

Run multiple playthroughs:
- OmniCorp-aligned;
- Merchant-aligned;
- independent;
- information broker;
- conflict exploiter.

## Acceptance gate

Stage 21 passes when:
- factions have internal groups;
- reputation is not the only relationship variable;
- ranks provide gameplay privileges;
- conflicts have multiple outcomes;
- faction missions emerge from state;
- economic consequences exist;
- faction technology matters;
- secrets can be used as leverage;
- NPCs reflect faction state;
- at least four viable faction strategies exist.
