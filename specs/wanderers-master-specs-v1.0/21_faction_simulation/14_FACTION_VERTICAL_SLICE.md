# Stage 21 Vertical Slice

## Conflict

OmniCorp ↔ Free Merchants over convoy route telemetry.

## Internal groups

OmniCorp:
- Security
- Research

Free Merchants:
- Convoy Union
- Independent Traders

## Player options

1. Support OmniCorp investigation.
2. Support merchants.
3. Keep evidence private.
4. Sell information.
5. Investigate both sides.
6. Broker a compromise.
7. Exploit the conflict economically.

## Required state changes

- faction trust;
- internal-group influence;
- player privileges;
- NPC relationships;
- evidence ownership;
- economic state;
- future mission availability.

## Success criterion

The player should be able to return to Solaris/Ferrum and see different:
- dialogue;
- mission offers;
- prices/services;
- faction behavior;
- NPC attitudes;
- access permissions.

No explicit quest marker is required.
