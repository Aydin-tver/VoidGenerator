# Source Handoff

To complete the source-dependent portion of Stage 13, provide the actual
Wanderers repository source tree, preferably the target branch.

Required:
- `lib/`
- `test/`
- `pubspec.yaml`
- narrative/event modules;
- save/load modules;
- any existing Void Event integration.

A ZIP upload is sufficient.

The audit will then replace `SOURCE_PENDING` with exact paths and produce:
1. source map;
2. patch plan;
3. implementation files;
4. tests;
5. integration report.
