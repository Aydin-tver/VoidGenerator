# Player Journey

## Phase A — Arrival

Player enters Ferrum through ordinary travel.

No quest marker is required.

Signals:
- unusual convoy timing;
- market price discrepancy;
- NPC rumor;
- registry inconsistency;
- sensor anomaly.

## Phase B — Curiosity

Player decides whether the anomaly matters.

Possible actions:
- ask;
- scan;
- trade information;
- inspect route;
- ignore.

## Phase C — Investigation

Player chooses an approach.

## Phase D — Interpretation

Evidence can be:
- incomplete;
- contradictory;
- misinterpreted;
- corroborated.

## Phase E — Decision

Possible decisions:
- report;
- withhold;
- sell information;
- investigate further;
- exploit the situation;
- protect a faction;
- expose a faction;
- walk away.

## Phase F — Consequences

World state changes.

## Phase G — Return

At least one NPC, faction, market or mission should visibly react after a meaningful delay.
