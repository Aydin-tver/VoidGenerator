# Vertical Slice Contract

## Required content

### Stations
1. Ferrum Central
2. Ferrum Relay
3. Ferrum Outpost

### Recurring NPCs
1. Lena Voss
2. Dispatcher Tidari
3. Engineer Nova
4. OmniCorp representative
5. Free Merchant representative
6. Tidari representative
7. Independent salvager
8. Security officer

### Factions
- Free Merchants
- OmniCorp
- Tidari
- Arcani

### Core problem

A convoy route has been altered by an unsigned correction. The correction appears operationally valid but its origin and consequences are unclear.

## Required player paths

At minimum:

- sensor investigation;
- commercial investigation;
- NPC/social investigation;
- faction-assisted investigation;
- exploration/discovery;
- engineering/equipment-assisted investigation;
- deliberate non-intervention.

## Required outputs

Every path must be capable of producing:

- information;
- a different risk profile;
- a different relationship/faction result;
- a different future opportunity;
- at least one persistent world consequence.
