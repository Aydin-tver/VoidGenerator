# Stage 31 Release Gate

Stage 31 is complete only when:

- Ferrum can be played without debug intervention;
- 3+ meaningful approaches exist for major problems;
- evidence can be gathered through multiple routes;
- NPC reactions persist;
- faction reactions persist;
- economy reacts;
- exploration can reveal relevant information;
- consequences survive save/load;
- failure does not create a dead end;
- at least two playthroughs produce materially different states;
- no authoritative state is duplicated by narrative runtime;
- performance remains acceptable on target mobile hardware.

This is a production gate, not a documentation gate.
