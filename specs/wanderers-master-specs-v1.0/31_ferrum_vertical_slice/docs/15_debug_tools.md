# Debug Tools

Required debug views:

1. Authoritative state inspector.
2. Narrative state inspector.
3. NPC memory viewer.
4. Faction reaction viewer.
5. Evidence graph viewer.
6. Economy state viewer.
7. World-event log.
8. Mission state viewer.
9. Capability resolver.
10. Consequence audit log.

Debug commands must be explicit and must not be required for normal gameplay.
