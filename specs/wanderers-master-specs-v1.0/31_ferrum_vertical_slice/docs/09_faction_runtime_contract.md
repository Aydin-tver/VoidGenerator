# Faction Runtime Contract

Each faction must track:

- relation;
- trust;
- access;
- rank;
- strategic goal;
- current pressure;
- resource priorities;
- reaction state;
- known player actions.

## Ferrum examples

Free Merchants:
protect convoy autonomy.

OmniCorp:
control commercial route data.

Tidari:
preserve registry integrity.

Arcani:
investigate anomalous information.

## Rule

Faction reaction must be based on actions and interests, not only reputation points.
