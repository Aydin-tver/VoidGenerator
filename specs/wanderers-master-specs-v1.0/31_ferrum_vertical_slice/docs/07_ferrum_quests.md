# Ferrum Systemic Quest Set

## FQ-01 Convoy Irregularity

Problem:
A convoy route has changed unexpectedly.

Approaches:
1. scan;
2. ask Lena;
3. inspect registry;
4. compare market data;
5. use faction access;
6. explore route;
7. ignore.

## FQ-02 Registry Report

Problem:
Unsigned route correction has legitimate formatting but questionable provenance.

Approaches:
- registry investigation;
- social pressure;
- evidence trade;
- technical analysis.

## FQ-03 Ferrum Anomaly

Problem:
A sensor anomaly is detected near a route relay.

Approaches:
- sensors;
- engineering;
- equipment;
- exploration;
- faction assistance.

## FQ-04 Nova's Interpretation

Problem:
Nova recognizes a technical pattern but lacks context.

Approaches:
- supply evidence;
- withhold evidence;
- trade evidence;
- ask for interpretation.

## FQ-05 SIGMA Signal

Problem:
Multiple independent clues point to a non-random pattern.

Approaches:
- investigate;
- report;
- sell;
- conceal;
- connect factions.

## FQ-06 Cross-Faction Pressure

Problem:
Factions want incompatible interpretations.

Approaches:
- align;
- mediate;
- exploit;
- expose;
- refuse.

## Requirement

At least 3 approaches must produce materially different outcomes for FQ-01, FQ-03 and FQ-06.
