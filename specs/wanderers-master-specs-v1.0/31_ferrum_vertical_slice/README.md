# Wanderers of the Void — Stage 31: Ferrum Systemic Vertical Slice v1.0

## Purpose

Turn the RPG architecture from Stages 17–30 into one production-grade playable slice.

Ferrum is the integration proving ground for:

- player agency;
- skills;
- equipment capabilities;
- factions;
- NPC memory/reactivity;
- dialogue gameplay;
- systemic quests;
- exploration;
- world simulation;
- economy;
- information gameplay;
- consequences;
- main-story progression.

## Definition of done

A player can enter Ferrum, discover a problem without being forced through a linear quest marker, investigate it using different capabilities, make a decision, and later observe consequences in NPC, faction, economic and narrative state.

The slice must be playable from start to finish without debug-only success paths.
