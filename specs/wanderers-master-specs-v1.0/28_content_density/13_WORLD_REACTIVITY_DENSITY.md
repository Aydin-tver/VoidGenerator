# World Reactivity Density v1.0

Target:
- 20–30 meaningful world-state transitions.
- 50+ NPC reactions to player actions.
- 30+ faction reactions.
- 20+ economic consequences.
- 20+ security changes.
- 15+ route changes.

Important player actions should leave traces.

Not every action requires a visible popup.

Consequences can appear later through:
- prices;
- dialogue;
- NPC behavior;
- route availability;
- faction access;
- new discoveries;
- mission availability.
