# Wanderers of the Void — Content Density System v1.0

## Purpose

Define the minimum amount, variety and systemic depth of content required for Wanderers of the Void to feel like a substantial RPG.

Content density is not raw content count.

A hundred identical fetch quests do not equal a hundred meaningful missions.

A content unit counts toward the target only when it provides meaningful:
- choice;
- information;
- gameplay;
- character development;
- faction interaction;
- exploration;
- economic opportunity;
- consequence;
- world change.

## Core principle

Every major system must have enough content to exercise it repeatedly in different contexts.

Architecture without content is not RPG depth.
