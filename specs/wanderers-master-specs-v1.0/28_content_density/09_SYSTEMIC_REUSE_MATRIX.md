# Systemic Reuse Matrix v1.0

Content should exercise multiple systems.

Example:

A single "missing convoy" situation can involve:

- exploration;
- sensors;
- piloting;
- combat;
- economy;
- Free Merchants;
- OmniCorp;
- NPC relationships;
- evidence;
- negotiation;
- equipment;
- future route security.

## Target

Major content should normally touch at least 3 systems.

Signature content should touch 5+.

This allows a relatively small amount of authored content to produce high systemic density.
