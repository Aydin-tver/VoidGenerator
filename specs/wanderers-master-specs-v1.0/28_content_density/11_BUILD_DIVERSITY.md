# Build Diversity v1.0

The player should be able to build different identities.

Target viable archetypes:

1. Signal Investigator
2. Independent Trader
3. Broker
4. Smuggler
5. Salvager
6. Engineer
7. Scout
8. Faction Operative
9. Combat Specialist
10. Hybrid Wanderer

A build is viable when it creates different:
- opportunities;
- information;
- approaches;
- risks;
- relationships;
- economic options;
- exploration options.

Do not balance builds solely around combat DPS.
