# Content Coverage Matrix v1.0

Every major system must be covered by multiple content units.

| System | Minimum distinct contexts |
|---|---:|
| Piloting | 15 |
| Engineering | 15 |
| Sensors | 15 |
| Commerce | 20 |
| Social | 15 |
| Covert | 10 |
| Equipment | 20 |
| Factions | 30 |
| NPC relationships | 25 |
| Exploration | 30 |
| Economy | 20 |
| Information gameplay | 20 |
| Consequences | 25 |
| World simulation | 20 |

A system with fewer contexts risks feeling decorative.
