# Content Production Pipeline v1.0

```text
SYSTEM REQUIREMENT
→ CONTENT GAP
→ CONTENT BRIEF
→ AUTHORING
→ SYSTEM TAGGING
→ REFERENCE GRAPH
→ NARRATIVE QA
→ SYSTEMIC QA
→ PLAYTEST
→ TELEMETRY
→ REVISION
→ RELEASE
```

Each content unit must identify:
- systems exercised;
- required capabilities;
- possible approaches;
- consequences;
- reuse potential;
- localization cost;
- implementation dependencies.

Content should be produced against coverage gaps, not randomly.
