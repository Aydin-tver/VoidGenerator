# Wanderers of the Void — Economic RPG System v1.0

## Purpose

Make economy a playable RPG system rather than a shop interface.

Core loop:

SUPPLY
→ DEMAND
→ PRICE
→ OPPORTUNITY
→ PLAYER ACTION
→ MARKET RESPONSE
→ FACTION/NPC RESPONSE
→ WORLD CONSEQUENCE
→ NEW OPPORTUNITY

The player can:
- trade;
- speculate;
- transport;
- stockpile;
- exploit shortages;
- create shortages;
- broker deals;
- smuggle;
- protect trade;
- manipulate information;
- invest;
- refuse profitable opportunities for strategic reasons.

## Principle

Credits are only one outcome.

Economic knowledge, access, relationships and information can be more valuable than immediate profit.
