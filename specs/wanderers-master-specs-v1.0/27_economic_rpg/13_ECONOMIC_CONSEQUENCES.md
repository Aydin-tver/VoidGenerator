# Economic Consequences v1.0

Player actions can cause:

Immediate:
- credits;
- cargo changes;
- price changes.

Medium:
- supply shifts;
- route changes;
- NPC opportunities;
- faction reactions.

Long:
- station specialization;
- persistent shortages;
- faction market dominance;
- new trade corridors;
- security changes;
- pirate migration.

Not every transaction should have a large consequence.

Only economically meaningful actions should propagate far.
