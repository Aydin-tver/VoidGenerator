# Price Discovery v1.0

The player should be able to understand that prices have causes.

Information sources:
- current station market;
- NPC rumors;
- merchant reports;
- previous transactions;
- faction intelligence;
- exploration;
- route observations.

Price states:
- stable;
- rising;
- falling;
- shortage;
- surplus;
- disrupted.

A price change should ideally be explainable:

"Ferrum price increased because refinery output fell."

This supports information gameplay.
