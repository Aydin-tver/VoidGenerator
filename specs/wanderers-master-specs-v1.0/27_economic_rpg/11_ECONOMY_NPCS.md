# Economy × NPCs v1.0

NPCs participate in the economy according to goals.

Examples:

Merchant:
- seeks profit.

Engineer:
- needs components.

Station official:
- needs stable supply.

Pirate:
- seeks valuable cargo.

Researcher:
- needs rare technology.

NPC economic actions can:
- change prices;
- create shortages;
- create missions;
- change relationships;
- alter faction priorities.

NPCs should not all know the same market information.
