# Wanderers of the Void — Equipment Gameplay System v1.0

## Purpose

Equipment is a gameplay capability system.

The player should install equipment not only to become stronger, but to change what the ship can do.

Core model:

EQUIPMENT
→ CAPABILITY
→ NEW ACTION / INFORMATION / RISK PROFILE
→ NEW APPROACH
→ DIFFERENT CONSEQUENCE

## Equipment roles

Equipment may provide:
- new actions;
- new information;
- access to dangerous or restricted areas;
- alternative mission solutions;
- safer or riskier approaches;
- economic opportunities;
- faction-specific interactions;
- exploration capabilities;
- combat options.

## Anti-stat rule

A major equipment item is incomplete if its only meaningful effect is:
- +damage;
- +armor;
- +speed;
- +cargo;
- -cooldown.

Those effects are useful, but RPG-defining equipment must also alter gameplay decisions.
