# Equipment × Build Interaction v1.0

Equipment should amplify different player builds.

## Signal Investigator
Sensors + Engineering + deep scanner + signal decoder.

## Independent Broker
Commerce + Social + market terminal + secure communications.

## Salvage Specialist
Engineering + Sensors + salvage rig + thermal shielding.

## Covert Courier
Piloting + Covert + silent drive + cargo isolation.

## Rule

Equipment should create build synergies without making skills irrelevant.

Skills determine:
- interpretation;
- expertise;
- reliability;
- options.

Equipment determines:
- what actions are physically possible;
- what information can be obtained;
- what environments can be entered;
- what risks can be tolerated.
