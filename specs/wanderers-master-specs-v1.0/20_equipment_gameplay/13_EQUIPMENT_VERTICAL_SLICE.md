# Stage 20 Equipment Vertical Slice

## Existing mystery

Ferrum anomaly / suspicious convoy route.

## Equipment options

### Basic Scanner
Provides raw anomaly data.

### Advanced Scanner
Provides pattern information.

### Signal Decoder
Allows structured transmission analysis.

### Salvage Rig
Allows investigation of damaged hardware.

### Silent Drive
Allows covert approach.

### Secure Cargo Module
Allows transport of sensitive evidence.

## Target

The same mystery can be approached differently depending on equipment.

Example:

Advanced Scanner:
→ discover signal pattern.

Signal Decoder:
→ identify structured message.

Salvage Rig:
→ recover physical evidence.

Silent Drive:
→ observe restricted site.

Secure Cargo:
→ transport evidence without normal inspection.

Equipment must change consequences and available options, not simply produce different text.
