# Equipment Capability Model v1.0

Separate item identity from the capability it grants.

```text
Item
  ↓
Capability
  ↓
Action
  ↓
Approach
  ↓
Outcome
```

## Capability examples

### Deep Scan
Allows high-resolution analysis of anomalies.

### Long-Range Sensor
Allows detection before entering a region.

### Signal Decoder
Allows interpretation of encoded transmissions.

### Emergency Repair
Allows limited field repair without station services.

### Cargo Isolation
Allows transport of sensitive cargo with reduced exposure.

### Thermal Shielding
Allows approach to hazardous environments.

### Silent Drive
Reduces detection during covert operations.

### Salvage Rig
Allows extraction of technology from wrecks.

### Negotiation Terminal
Provides market/faction data useful during trade decisions.

Capabilities should be queryable by missions and gameplay systems.
