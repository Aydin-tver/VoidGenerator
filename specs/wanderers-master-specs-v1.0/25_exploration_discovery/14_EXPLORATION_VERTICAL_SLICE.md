# Stage 25 Vertical Slice

## Discovery: Ghost Relay

The player encounters an unusually weak signal while travelling near Ferrum.

No quest is active.

### Path A — Ignore
Nothing immediately happens.

Later:
another faction may discover the relay.

### Path B — Basic scan
Player detects an old relay signature.

Creates:
knowledge + rumor.

### Path C — Advanced scan
Reveals a modified signal pattern.

Creates:
evidence + anomaly.

### Path D — Signal decoder
Extracts a partial registry identifier.

Creates:
new lead.

### Path E — Engineering
Player recovers a damaged relay component.

Creates:
physical evidence.

### Path F — Covert approach
Player observes a hidden transfer.

Creates:
faction evidence.

### Possible discoveries

- abandoned relay;
- manipulated registry;
- old cargo route;
- hidden faction operation;
- SIGMA-related fragment.

The player decides whether to:
- investigate;
- sell information;
- report it;
- hide it;
- use it as leverage.

No GPS-style quest pointer is required.
