# Rumor System v1.0

Rumors are information leads.

```yaml
rumor_id:
source:
content:
subject:
reliability:
age:
bias:
supporting_evidence:
contradicting_evidence:
possible_locations:
possible_actors:
discovery_state:
```

Reliability should not equal truth.

A highly reliable NPC can still be mistaken.

Rumors can evolve:
rumor → observation → evidence → verified fact.

Or:
rumor → contradiction → false lead.

The player decides whether investigation is worth the cost.
