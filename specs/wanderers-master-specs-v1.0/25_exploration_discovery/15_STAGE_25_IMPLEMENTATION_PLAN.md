# Stage 25 Implementation Plan

## Phase 1
Implement:
- Discovery;
- Rumor;
- Anomaly;
- HiddenLocation;
- HiddenRoute;
- DiscoveryEvidence.

## Phase 2
Connect to:
- Knowledge/Evidence;
- Skills;
- Equipment;
- NPC;
- Factions;
- Economy;
- World Simulation.

## Phase 3
Create discovery director.

It should surface opportunities from world state without generating arbitrary content.

## Phase 4
Implement Ghost Relay vertical slice.

## Phase 5
Create discovery chains and mystery seeds.

Target:
- 10 reusable discovery archetypes;
- 20 mystery seeds;
- 10 hidden locations;
- 10 hidden route opportunities.

## Acceptance gate

Stage 25 passes when:
- meaningful discoveries exist without active quests;
- rumors can be true/false/partial;
- anomalies produce evidence;
- skills/equipment change discovery quality;
- hidden locations/routes exist;
- discoveries can create future missions;
- exploration has risk;
- knowledge is a meaningful reward;
- player can stop or pursue a mystery;
- no universal GPS marker is required.
