# Discovery Chains & Mysteries v1.0

Discovery chains are non-linear investigation structures.

Example:

Weak signal
→ abandoned probe
→ corrupted registry fragment
→ unusual cargo route
→ hidden relay
→ conflicting faction evidence
→ SIGMA connection

Each step should be discoverable through:
- curiosity;
- information;
- capability;
- experimentation.

The player may:
- stop;
- continue;
- sell information;
- report it;
- hide it;
- investigate a different branch.

Mysteries should create questions, not only rewards.
