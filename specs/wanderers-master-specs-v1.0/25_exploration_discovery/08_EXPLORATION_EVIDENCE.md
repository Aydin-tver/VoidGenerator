# Exploration Evidence System v1.0

A discovery should often create evidence.

Evidence types:
- scan;
- log;
- recording;
- physical artifact;
- cargo manifest;
- registry entry;
- testimony;
- transaction record;
- wreck component.

Evidence has:
- source;
- reliability;
- interpretation;
- connections;
- contradictions.

Multiple discoveries can combine into a theory.

The game should allow the player to hold an unresolved mystery without immediately providing the answer.
