# Wanderers of the Void — Exploration & Discovery System v1.0

## Goal

Create meaningful exploration that does not require a formal quest marker.

The player should be able to discover:
- hidden locations;
- anomalies;
- abandoned ships;
- secret routes;
- unusual cargo;
- old signals;
- faction activity;
- lost technology;
- lore fragments;
- NPC leads;
- economic opportunities;
- mysteries.

Core loop:

RUMOR / OBSERVATION
→ CURIOSITY
→ HYPOTHESIS
→ INVESTIGATION
→ DISCOVERY
→ INTERPRETATION
→ CHOICE
→ CONSEQUENCE
→ NEW LEAD

## Core principle

The world must contain things worth investigating even when the quest journal says nothing.

Exploration is driven by knowledge, capability and player curiosity.
