# Discovery Sources v1.0

Discoveries may originate from:

- NPC dialogue;
- rumors;
- cargo manifests;
- station records;
- sensor readings;
- visual observation;
- faction relationships;
- economic anomalies;
- previous missions;
- equipment;
- skills;
- failed missions;
- world events;
- exploration itself.

Important:
The player should not always be told exactly what the source means.

A rumor can be:
- true;
- partially true;
- false;
- outdated;
- deliberately planted.
