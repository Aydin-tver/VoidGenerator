# Quest Outcome Model v1.0

Use graded outcomes.

## Failure

The primary objective is not achieved.

Failure still changes the world.

## Partial success

The player achieves some objectives but creates a cost or loses another objective.

## Success

Primary objective achieved.

## Exceptional success

Primary objective achieved with additional strategic benefit.

Example:

Convoy protection:

Failure:
cargo lost.

Partial:
cargo survives but convoy reputation falls.

Success:
cargo delivered.

Exceptional:
cargo delivered and attacker network identified.
