# Wanderers of the Void — Systemic Quests v1.0

## Goal

A quest is a problem in the world, not a fixed sequence of instructions.

Core model:

PLAYER GOAL
→ INFORMATION
→ PREPARATION
→ APPROACH
→ ACTION
→ RESULT
→ CONSEQUENCES
→ WORLD RESPONSE
→ NEW OPPORTUNITIES

## Quest quality rule

A major quest should provide at least three materially different approaches.

The approaches must differ in:
- required capabilities;
- risk;
- information;
- resources;
- NPC/faction relationships;
- consequences.

## Anti-rail rule

Avoid:

ACCEPT → TRAVEL → TALK → COLLECT → RETURN → REWARD

unless the mission is intentionally a simple low-value task.

Major missions must contain a decision space.
