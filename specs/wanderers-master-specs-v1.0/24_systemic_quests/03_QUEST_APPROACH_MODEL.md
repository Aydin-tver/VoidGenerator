# Quest Approach Model v1.0

Approaches are gameplay strategies.

Examples:

- investigate;
- negotiate;
- trade;
- escort;
- evade;
- fight;
- sabotage;
- deceive;
- gather evidence;
- exploit faction conflict;
- use specialized equipment;
- use skill expertise;
- abandon objective.

A single quest may support several approaches.

Each approach should have:
- requirements;
- cost;
- risk;
- information outcome;
- immediate result;
- downstream consequence.
