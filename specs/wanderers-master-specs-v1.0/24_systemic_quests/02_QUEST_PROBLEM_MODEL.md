# Quest Problem Model v1.0

A systemic quest contains:

```yaml
quest_id:
problem:
player_goals:
world_stakes:
known_information:
unknown_information:
actors:
resources:
constraints:
available_capabilities:
approaches:
failure_conditions:
partial_success_conditions:
success_conditions:
consequence_set:
future_hooks:
```

The quest describes the problem and state transitions.

It does not prescribe a single route.
