| System | Must interact with |
|---|---|
| Player Agency | all major systems |
| Skills | missions, exploration, equipment, dialogue |
| Equipment | exploration, missions, combat, trade, information |
| Knowledge | missions, dialogue, exploration, factions |
| NPC | dialogue, factions, missions, stations, consequences |
| Factions | NPC, missions, economy, world, access |
| Economy | factions, stations, routes, missions |
| Exploration | knowledge, equipment, missions, lore |
| Consequences | NPC, faction, economy, world, future content |
| World State | missions, NPC, factions, economy, encounters |

## Systemic Density

Systemic Density measures how many meaningful systems a feature can influence.

For major gameplay features:

1–2 interactions = weak
3–4 = acceptable
5–6 = strong
7+ = systemic

Major missions should target 5+ systemic interactions.
Major factions should target 7+.
Major discoveries should target 4+.
