# NPC System Requirements v1.0

Recurring NPCs need:

- identity
- goal
- fear
- secret
- faction
- knowledge
- trust
- disposition
- memory
- relationships
- services
- mission hooks
- reaction rules
- state-dependent dialogue

## NPC memory

Memory should record meaningful player actions, not every click.

Example:
- helped NPC
- betrayed NPC
- exposed secret
- delivered evidence
- withheld evidence
- caused faction conflict
- saved cargo
- destroyed target

## Relationship dimensions

Use separate values where needed:
- trust
- respect
- fear
- dependence
- ideological alignment

Do not reduce all relationships to one affection score.
