# Solaris — RPG Node v0.6

## Identity
Solaris is the player's early-world anchor: commerce, ordinary work, first relationships and the first visible contradiction.

## Narrative role
Teach the player:
- how ordinary work functions;
- how factions request things;
- that information has value;
- that the world can disagree with itself.

## Core NPCs
- Lena Voss — convoy/trade;
- Dispatcher Tidari — registry;
- functional station personnel.

## Local conflict
A convoy route has conflicting information.

The conflict initially looks mundane:
- registry correction;
- convoy safety;
- competing institutional interests.

## Hidden layer
The correction is not properly attributable.

## Station mission pool
1. ordinary convoy/trade job;
2. convoy irregularity;
3. registry report;
4. optional information gathering;
5. follow-up after player choice.

## State changes
After the player's decision:
- NPC dialogue changes;
- mission availability changes;
- faction context changes;
- evidence journal gains/changes entries.

## Living Space connection
When the player returns to the ship:
- mission/evidence state can be reviewed;
- NPC message may appear;
- player can reflect on the anomaly;
- no separate fictional gameplay system is required.
