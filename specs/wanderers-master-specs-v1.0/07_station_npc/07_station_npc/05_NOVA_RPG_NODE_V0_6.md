# Nova — RPG Node v0.6

## Identity
Nova is the next station node after Ferrum and a place where the player can compare information gathered from earlier locations.

## Narrative role
Turn isolated clues into a cross-source pattern.

## Core functions
- technical interpretation;
- equipment/progression context;
- faction pressure;
- evidence comparison.

## Character network
Nova should connect:
- Engineer Nova;
- Arcani interpretation;
- relevant commercial/registry interests;
- the player's ship capability.

## Mission hooks
- technical follow-up;
- evidence delivery;
- equipment-dependent investigation;
- faction request concerning the same evidence.

## Rule
A new station must introduce a new perspective, not repeat the previous station's exposition.
