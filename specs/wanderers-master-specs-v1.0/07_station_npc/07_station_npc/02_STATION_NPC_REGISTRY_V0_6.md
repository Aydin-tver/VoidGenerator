# Wanderers — Station NPC Registry v0.6

## NPC tiers

### Tier 0 — Functional
No persistent arc. Provides service/information.

### Tier 1 — Recurring
Remembers selected player actions and provides changing context.

### Tier 2 — Major
Owns a character arc and participates in faction/main-story conflicts.

## Anti-clutter rule

A station should not have 20 named NPCs merely to look populated.

Prefer:
- 2–4 meaningful named NPCs;
- functional anonymous services;
- information generated by the named network.
