# Ferrum — RPG Node v0.6

## Identity
Ferrum is the transition from ordinary commerce into technical investigation and physical risk.

## Narrative role
Prove that the Solaris anomaly has an independent counterpart.

## Core NPC
Engineer Nova.

## Local conflict
A technical anomaly can be interpreted as:
- equipment failure;
- deliberate alteration;
- evidence of an older system.

The player must acquire evidence before choosing an interpretation.

## Gameplay
- travel;
- scan/discovery;
- salvage;
- combat if the encounter requires it and the combat system supports it;
- docking;
- equipment progression.

## NPC function
Nova should not explain the entire mystery. Nova provides:
- technical observation;
- a practical hypothesis;
- a reason to investigate further.

## Station state
Ferrum may move from normal → technical alert → investigation complete.

The exact state transition must be backed by implemented world/narrative state.
