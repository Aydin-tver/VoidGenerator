# Stage 18 Agency Vertical Slice

## Scenario

Existing chain:

Convoy Irregularity
→ Registry Report
→ REPORT / WITHHOLD
→ Ferrum Anomaly
→ Nova
→ SIGMA signal

## Rebuild target

The player learns:

- a route amendment exists;
- the registry record is suspicious;
- Ferrum contains an anomaly;
- different sources disagree.

Instead of receiving one prescribed mission chain, the player can:

### Path A — Official investigation
Report the discrepancy and use institutional channels.

### Path B — Independent investigation
Withhold the report and investigate Ferrum directly.

### Path C — Social investigation
Question Tidari, Nova and faction contacts.

### Path D — Technical investigation
Use scan capability/equipment to gather independent evidence.

### Path E — Economic leverage
Trade or sell information to interested parties.

### Path F — Ignore
Continue normal work. The world can evolve without the player.

## Required consequences

At least:
- NPC reaction
- faction reaction
- knowledge change
- one delayed consequence
- one new opportunity
- one lost opportunity

## No fake freedom

The paths must not converge immediately to:
"Player discovers SIGMA and continues MSR-05."

They should produce different context, access, evidence, relationships and risks before the common mystery arc continues.
