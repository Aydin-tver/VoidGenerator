# Player-Created Objectives v1.0

## Purpose

The game should support objectives that were not authored as explicit quest steps.

## Examples

### Rumor-driven
"Someone mentioned an abandoned relay near a dangerous route."

### Evidence-driven
"Two registry entries contradict each other."

### Economic
"Ferrum suddenly lacks reactor components."

### Relationship-driven
"Nova stopped answering after the last investigation."

### Exploration-driven
"A signal appears only during a certain route condition."

## Objective handling

Player-created objectives may be:

- saved
- named
- tracked
- abandoned
- completed
- transformed into another objective

## No GPS requirement

The game should provide:
- known facts
- partial directions
- source context
- relevant system/station names
- approximate region information

It should not require an artificial arrow or "show route" button.
