# Wanderers — Endgame State Preparation v0.5

## Ending is not a single boolean

Do not model the finale as:

```text
ending = 1..5
```

Instead calculate a final narrative state from existing authoritative domains.

## Inputs

### Player identity
What the player repeatedly chose to protect, reveal, conceal, investigate or reject.

### Faction relationships
Trust/hostility/access values already owned by the faction system.

### Character state
Trust, relationship, availability and arc completion where supported by narrative state.

### Knowledge
Evidence, discoveries and unresolved contradictions.

### World state
Registered world consequences.

### Thread state
Resonance/discovery progression.

## Ending families

1. **Containment** — discovery is placed under controlled institutional handling.
2. **Disclosure** — knowledge is distributed more broadly.
3. **Independence** — player rejects exclusive ownership by established powers.
4. **Non-intervention** — player limits active interference while preserving knowledge.
5. **Open Continuation** — evidence remains incomplete and the player leaves the deeper question unresolved.

These are narrative families, not moral rankings.

## Variation layer

Each family can vary by:
- dominant faction relationships;
- surviving/available characters;
- trust with key NPCs;
- evidence completeness;
- unresolved mysteries;
- world consequences.

## Second-part bridge

The Voidari / Consciousness Transfer thread should remain capable of continuing into a later story epoch. The first game may reveal enough to establish the question without resolving all technical and philosophical consequences.
