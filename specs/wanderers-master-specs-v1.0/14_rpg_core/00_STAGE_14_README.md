# Wanderers — Stage 14: RPG Core Systems v1.0

## Purpose

This stage converts the Morrowind-level design gap audit into six concrete
system specifications.

The objective is NOT to add more lore documents. The objective is to make
player knowledge, faction relationships, NPC memory, consequences, world
reaction and equipment capabilities interact as gameplay.

## Six systems

1. Information / Knowledge
2. Faction Progression
3. NPC Memory
4. Consequence Propagation
5. World / Station Reactivity
6. Equipment → Narrative Capability

## Core loop

GOAL → INFORMATION → INTERPRETATION → PREPARATION → GAMEPLAY →
CHOICE → CONSEQUENCE → WORLD RESPONSE → NEW INFORMATION

## Hard rule

No system may invent unsupported gameplay capabilities. Every effect must
resolve through the existing event / host adapter architecture.

## Completion criterion

A player must be able to make a meaningful decision based on information,
see an immediate or delayed consequence, and encounter changed narrative
context later without the main quest explicitly telling them that the world
changed.
