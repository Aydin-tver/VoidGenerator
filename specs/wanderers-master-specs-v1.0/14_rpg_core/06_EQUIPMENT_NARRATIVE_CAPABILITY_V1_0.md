# 06 — Equipment → Narrative Capability v1.0

## Purpose

Turn equipment progression into access to different gameplay possibilities.

## Capability axes

Recommended initial axes:

```text
COMBAT
MOBILITY
SURVIVAL
CARGO
SCAN
STEALTH
```

Thread/AI capabilities may be added only when technically supported.

## Capability gate

A narrative opportunity can require:

```text
capability >= threshold
```

or:

```text
capability A OR capability B
```

This creates alternative solutions.

## Examples

### Scan
Advanced scanner reveals an anomaly.

### Cargo
Large hold enables a risky independent contract.

### Stealth
Player can pass a monitored checkpoint without triggering combat.

### Mobility
High mobility enables escape from a dangerous encounter.

### Survival
Hazard-resistant ship can reach an optional discovery.

### Combat
Strong combat build can resolve a hostile blockade.

## Critical rule

Equipment must not simply unlock "better dialogue".

It should unlock a different action or opportunity.

## Alternative solution

A major objective should sometimes have:

```text
combat solution
OR
stealth solution
OR
investigation solution
OR
trade/information solution
```

Only include branches that the runtime can actually execute.
