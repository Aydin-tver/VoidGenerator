# 02 — Faction Progression System v1.0

## Purpose

Make factions playable identities rather than quest categories.

## Faction state

```text
unknown
contacted
trusted
member
recognized
senior
conflicted
rival
blocked
```

Actual rank names are faction-specific.

## Faction dimensions

Every major faction has:

- reputation;
- trust;
- standing/rank;
- known secrets;
- completed obligations;
- unresolved conflicts;
- rival relations;
- exclusive opportunities.

## Advancement

Advancement requires more than reputation points.

Possible requirements:

- completed obligation;
- discovered evidence;
- capability;
- relationship;
- faction-specific choice;
- previous conflict resolution.

## Internal conflict

Every major faction must contain at least two competing interests.

Example:

```text
Free Merchants

Independent merchants
        vs
Large convoy operators
```

The faction therefore cannot be reduced to "good faction".

## Cross-faction consequences

A faction action can alter another faction's context.

```text
help Tidari
 → restricted information
 → OmniCorp distrust
 → new merchant rumor
 → alternative investigation route
```

## Exclusive content

Faction progression can unlock:

- information;
- missions;
- equipment;
- contacts;
- routes;
- discounts;
- narrative options.

## Incompatibility

Some major choices must create real opportunity cost.

Never present every faction reward simultaneously in one run.
