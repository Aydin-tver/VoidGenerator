# 07 — System Interaction Matrix

The six systems become valuable only when connected.

| From | To | Example |
|---|---|---|
| Information | Faction | evidence earns trust |
| Information | NPC | NPC reacts to what player knows |
| Information | Mission | clue unlocks investigation |
| Faction | NPC | faction pressure changes relationship |
| Faction | World | faction conflict changes station |
| NPC | Information | character provides unique clue |
| NPC | Consequence | betrayal changes future contact |
| Consequence | World | station state changes |
| World | NPC | NPC dialogue reflects new state |
| Equipment | Information | scanner reveals evidence |
| Equipment | Mission | capability opens alternative |
| Equipment | Faction | specialized capability earns opportunity |
| World | Information | changed station produces new clues |

## Minimum chain

Every major RPG story unit should ideally touch at least 3 systems.

Example:

```text
equipment
 → discovery
 → evidence
 → faction choice
 → NPC reaction
 → station change
 → new information
```
