# Stage 14 Gate

Stage 14 is complete only when:

- [ ] information state exists;
- [ ] faction progression exists;
- [ ] NPC memory exists;
- [ ] consequence propagation exists;
- [ ] station/world reactivity exists;
- [ ] equipment narrative capability exists;
- [ ] all six use the event/adapter architecture;
- [ ] save/load preserves all state;
- [ ] replay is idempotent;
- [ ] one vertical slice demonstrates cross-system interaction;
- [ ] at least two meaningful player trajectories work;
- [ ] no GPS dependency exists;
- [ ] no unsupported mechanic is authored;
- [ ] tester can observe consequences without being explicitly told.

Do not scale to dozens of new missions until this gate is satisfied.
