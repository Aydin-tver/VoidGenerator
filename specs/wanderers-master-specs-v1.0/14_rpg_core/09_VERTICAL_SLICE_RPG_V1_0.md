# 09 — RPG Core Vertical Slice

Before scaling content, build one complete chain.

## Scenario

Convoy irregularity → registry contradiction → Ferrum anomaly → faction
pressure → player choice → delayed consequence → return to Solaris.

## Required systems

- Information
- Faction progression
- NPC memory
- Consequence propagation
- Station reactivity
- Equipment capability

## Required player experience

### First pass

Player reports evidence.

Result:
Tidari trust increases.
Later information becomes available.
OmniCorp context becomes more suspicious.

### Alternative pass

Player withholds evidence.

Result:
Lena trust changes.
Different information source becomes available.
Later investigation begins from a different premise.

### Equipment alternative

A capable scanner discovers an additional clue.

A combat-focused build can instead obtain the clue through a dangerous encounter.

No GPS is used.

## Acceptance

A tester must be able to explain:

- what they knew;
- why they chose;
- what changed;
- what they discovered later;
- which opportunity they lost or gained.
