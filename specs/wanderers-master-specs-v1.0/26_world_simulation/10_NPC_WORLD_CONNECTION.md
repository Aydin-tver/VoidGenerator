# NPC → World Simulation v1.0

NPC goals can create world actions.

Examples:

Merchant needs profit
→ seeks shortage route.

Engineer needs rare component
→ creates procurement request.

Dispatcher fears security failure
→ reports suspicious traffic.

Pirate wants resources
→ targets profitable convoy.

Faction officer wants promotion
→ initiates investigation.

NPC actions can change:
- faction state;
- economy;
- station services;
- security;
- missions;
- relationships;
- discoveries.
