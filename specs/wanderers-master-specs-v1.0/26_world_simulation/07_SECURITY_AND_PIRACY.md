# Security & Piracy Simulation v1.0

Security responds to threats.

Inputs:
- piracy;
- smuggling;
- faction conflict;
- recent incidents;
- cargo value;
- player actions;
- intelligence.

Security responses:
- patrols;
- inspections;
- escorts;
- restrictions;
- bounties;
- investigations;
- temporary route closures.

Piracy responds to:
- profitable routes;
- weak security;
- faction conflict;
- resource shortages;
- opportunities.

Piracy should not be random decoration.
