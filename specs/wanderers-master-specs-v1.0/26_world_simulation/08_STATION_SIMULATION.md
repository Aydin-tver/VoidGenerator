# Station Simulation v1.0

Stations are economic and social hubs.

Station state includes:

- population/activity;
- inventory;
- demand;
- security;
- faction presence;
- available services;
- active conflicts;
- NPC activity;
- rumors;
- opportunities.

A station can change because of:
- shortage;
- security incident;
- faction pressure;
- player action;
- trade;
- migration;
- damaged infrastructure;
- discovery.
