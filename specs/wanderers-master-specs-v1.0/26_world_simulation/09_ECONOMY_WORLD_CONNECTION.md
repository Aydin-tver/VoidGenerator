# Economy → World Simulation v1.0

Economic state creates world pressure.

Example:

Ore shortage
→ price rises
→ merchants enter route
→ piracy opportunity increases
→ security increases
→ smuggling becomes profitable
→ faction pressure rises
→ NPC missions appear.

The economic system therefore generates gameplay.

Do not create separate 'economic events' merely for flavor when an economic cause can drive the event naturally.
