# Faction → World Simulation v1.0

Faction strategy operates through resources and actions.

Resources:
- credits;
- technology;
- logistics;
- influence;
- intelligence;
- security capacity.

Faction decisions can:
- alter prices;
- protect routes;
- restrict technology;
- deploy security;
- create missions;
- manipulate information;
- support NPCs;
- pressure stations.

Internal groups compete for priorities.

This prevents factions from behaving like static reputation meters.
