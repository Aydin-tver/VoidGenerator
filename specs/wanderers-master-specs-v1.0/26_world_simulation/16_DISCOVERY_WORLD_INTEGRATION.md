# Exploration → World Simulation v1.0

Stage 25 discoveries become world inputs.

Examples:

Discover hidden pirate route
→ security can react.

Discover abandoned resource site
→ economy can react.

Discover faction operation
→ faction intelligence changes.

Discover old relay
→ new NPC/faction goals may appear.

Discover secret route
→ traffic can eventually shift.

Important:
Discovery does not automatically reveal every consequence.

The player may discover something and choose not to report it.

Information itself becomes a world resource.
