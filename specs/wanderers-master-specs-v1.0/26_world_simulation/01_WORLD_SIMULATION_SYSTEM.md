# Wanderers of the Void — World Simulation System v1.0

## Purpose

Connect the existing RPG systems into one causal world simulation.

The world must not be a collection of isolated systems.

Core loop:

WORLD STATE
→ ACTORS
→ INTENTIONS
→ ACTIONS
→ INTERACTIONS
→ STATE CHANGES
→ CONSEQUENCES
→ NEW INTENTIONS

Systems connected:

- NPC
- Factions
- Economy
- Security
- Piracy
- Routes
- Stations
- Missions
- Exploration
- Knowledge
- Player actions

## Core principle

Every significant world event should have:
1. a cause;
2. an actor;
3. resources/capabilities;
4. an action;
5. a result;
6. consequences.

Avoid arbitrary random events without world causes.
