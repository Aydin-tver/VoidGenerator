# Routes & Traffic Simulation v1.0

Routes connect stations and regions.

Route state includes:

- traffic volume;
- cargo value;
- travel risk;
- security;
- faction influence;
- piracy pressure;
- delays;
- shortages;
- special conditions.

Traffic should be generated from economic demand and actor intentions.

Examples:

Shortage
→ high cargo value
→ more merchants
→ more pirates
→ increased security
→ higher operating cost
→ price changes.

The route therefore becomes a systemic object.
