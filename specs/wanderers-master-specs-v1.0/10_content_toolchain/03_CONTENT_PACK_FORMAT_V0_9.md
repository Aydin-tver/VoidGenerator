# Content Pack Format v0.9

## Root

```json
{
  "pack_id": "wanderers_story_vertical_slice",
  "pack_version": "0.9.0",
  "schema_version": "0.9",
  "content": {
    "missions": [],
    "dialogues": [],
    "evidence": [],
    "characters": [],
    "stations": [],
    "consequences": []
  }
}
```

## Metadata

Every pack should include:
- pack_id;
- pack_version;
- schema_version;
- build timestamp generated by tooling;
- source revision if available;
- content list.

## Determinism

Given identical source content and validator version, the built pack must be deterministic except generated metadata such as build timestamp.

## Runtime contract

Runtime accepts only validated pack versions compatible with its supported schema range.
