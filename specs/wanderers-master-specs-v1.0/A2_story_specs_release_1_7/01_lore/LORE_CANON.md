# LORE_CANON — реестр канон-фактов мира Wanderers

> Канон = то, что обязано быть истинным во всех текстах игры.
> Статусы: CANON (истина), PARTIAL (частично известна миру), RUMOR (слух,
> может быть ложью), FALSE_IN_WORLD (ложь внутри мира — официальная версия),
> PLAYER_DISCOVERY (открывается игроком), UNKNOWN (замалчивается всеми).
> Правила противоречий: см. §Канон-правила. Источник данных: lore.json (54 записи),
> story.json, character_arcs.json. Синхронизация сущностей: design/registry/entities.yaml.

## 5. Загадки (mystery, 9 записей)

Головная линия «СИГМА ↔ Нить»: первый контакт → вопрос об архитектуре → невозможные
системы → общая аномалия → ответ из Нити → сходство → вопрос к себе → архитектурное
сходство → **«Это не доказательство»** (закрытия не даёт — намеренно, mystery не
решается в MVP, держит hook для Этапа 5).

## Канон-правила (запрещённые противоречия)

1. Игрок — ИИ корабля. Никаких «пилотов-людей» в нарративе (вводная, lore_main_01, /identity).
2. Нить не объясняется в диалогах-лекциях — только через улики и mystery-ветку (Audit-1 §9).
3. Фракции не good/evil: у каждой — скрытая повестка и внутренние группы (таблица §3).
4. Один термин — одно имя (см. TERMINOLOGY.md; вариации из таблицы «нарушений» запрещены).
5. Финал «Кайрос без Реестра» — только через флаг zazor_identity_protected (char_sera_01); пока не расспарено — не добавлять второй источник флага без ADR.
6. «Это не доказательство» (sigma_not_proof) — замысел: mystery-ветка НЕ даёт окончательного ответа в 1.4.
7. Мир живёт без игрока: жёсткие последствия — только через worldConsequences (piracy/security/smuggling/thread), без «оценок» GOOD/EVIL.

## Пустоты (для контентных бэклогов)

- Хор Проклятых (choir) — фракция без единого квеста;
- станции/системы без описаний (8 станций в universe.json — сухие конфиги);
- «Верда», «Игнис» — упомянуты в лоре, не существуют в мире;
- evidence от геймплейных миссий не подключены к финалам (Story Graph, пробел 5).
