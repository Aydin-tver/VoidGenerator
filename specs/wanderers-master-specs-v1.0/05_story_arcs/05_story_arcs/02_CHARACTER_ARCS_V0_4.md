# Wanderers — Character Arcs v0.4

## Character rule
A major character is not a lore container. Their arc must create a change in at least one of:
- player knowledge;
- relationship/trust;
- faction access;
- evidence;
- future mission availability;
- world consequence.

## Existing named anchors
### Lena Voss
Role: Free Traders / convoy captain.
Arc question: how far can independence survive when convoy safety depends on powerful institutions?
Gameplay: convoy, travel, trade, protection/loss.
Stages:
1. practical introduction;
2. convoy problem;
3. route anomaly;
4. pressure from competing interests;
5. player-dependent outcome.

### Dispatcher Tidari
Role: registry dispatcher / archival authority.
Arc question: is information a public service or controlled property?
Gameplay: docking, discovery, evidence, information gates.
Stages:
1. official contact;
2. registry discrepancy;
3. request for evidence/report;
4. conflict over disclosure;
5. post-choice relationship/access.

### Engineer Nova
Role: station engineer.
Arc question: practical survival vs institutional demands.
Gameplay: equipment/ship progression and technical consequences.
Stages:
1. technical assistance;
2. ship/system problem;
3. discovery of unusual component data;
4. interpretation conflict;
5. equipment or information consequence.

## Character relationship rules
Each Tier-1 character must have:
- faction;
- home/primary station;
- main-story question;
- gameplay system;
- another character relationship;
- potential consequence;
- knowledge state;
- trust state.

## Death/exit rule
A character may disappear only if the game can represent the consequence. Otherwise use non-terminal outcomes such as loss of access, silence, refusal, relocation flag, or changed relationship.
