# Quest Pattern Library

Avoid repetitive:

```text
go → kill → return
go → fetch → return
```

Use combinations:

1. Escort + investigation
2. Trade + political choice
3. Salvage + ownership dispute
4. Combat + evidence discovery
5. Exploration + faction secret
6. Delivery + conflicting instructions
7. Rescue + reputation consequence
8. Scan + false interpretation
9. Rumor + optional discovery
10. Equipment gate + alternate solution
11. Two factions claim same object
12. NPC asks player to hide information
13. Player discovers quest without mission acceptance
14. Previous decision changes objective
15. Failure creates a different future quest
