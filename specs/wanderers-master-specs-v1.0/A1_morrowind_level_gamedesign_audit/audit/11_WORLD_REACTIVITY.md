# 11 — World Reactivity Gap

Stations currently have narrative-state concepts. They need visible persistence.

After a major event:

```text
station dialogue changes
mission pool changes
rumors change
merchant opportunities change
NPC trust changes
faction presence changes
available information changes
```

The player should be able to return later and notice:

> "The world remembers."

This does not require a simulated economy or autonomous NPC schedules.
Narrative state transitions are sufficient if they are visible and persistent.
