# 05 — NPC Depth Gap

Current named NPCs are narrative anchors. The target is a persistent network.

Every important NPC should have:

```text
goal
fear
resource
secret
knowledge
misconception
relationships
faction position
player trust
memory
state transitions
```

## NPC reaction tiers

### Tier 0
Static.

### Tier 1
Remembers completed mission.

### Tier 2
Reacts to player choices.

### Tier 3
Reacts to faction/world state.

### Tier 4
Provides new information, mission or opportunity because of player history.

### Tier 5
Can become ally, rival, source, obstacle or lost opportunity.

The goal is not simulated daily life. It is **persistent narrative memory**.
