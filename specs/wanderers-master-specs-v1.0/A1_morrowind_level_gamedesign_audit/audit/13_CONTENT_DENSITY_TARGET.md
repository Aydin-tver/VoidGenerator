# 13 — Content Density Target

The current vertical slice is a prototype, not the final content scale.

## Recommended first production target

Before calling the game Morrowind-depth, build approximately:

### Main story
30–45 missions

### Major factions
8–12 missions each

### Character arcs
5–8 missions for each major recurring character

### Stations
3–6 meaningful local quest/evidence chains per major station

### Secrets
At least 50 independently discoverable lore/evidence nodes

### Ambient narrative
100+ short contextual dialogue/rumor/info nodes

### Exploration
30+ optional discoveries

These are production planning targets, not claims about Morrowind's exact
content counts.
