# 03 — Core Player Loop Gap

Current intended loop:

```text
route → risk → decision → reward → progression → next route
```

This is a good economic/exploration loop but insufficient for a deep RPG.

Target loop:

```text
GOAL
 ↓
INFORMATION
 ↓
INTERPRETATION
 ↓
PREPARATION
 ↓
TRAVEL / GAMEPLAY
 ↓
DECISION
 ↓
CONSEQUENCE
 ↓
NEW INFORMATION
 ↓
WORLD RESPONSE
 ↓
NEW GOAL
```

The crucial additions are:

- information as a resource;
- interpretation;
- persistent consequences;
- world response;
- self-generated goals.

## Example

NPC says:
"Three convoy manifests were amended before departure."

Player can:
- report it;
- investigate;
- ignore it;
- sell the information;
- ask another faction;
- compare records.

The gameplay should not require one correct answer.
