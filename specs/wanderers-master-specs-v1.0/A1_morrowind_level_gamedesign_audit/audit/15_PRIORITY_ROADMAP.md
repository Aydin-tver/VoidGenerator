# 15 — Correct Production Order

Do NOT start by writing hundreds of generic quests.

## Phase A — Systems

1. Information/evidence gameplay
2. Faction progression
3. NPC memory
4. Consequence propagation
5. World/station state
6. Equipment-as-capability

## Phase B — Content foundations

7. Build 3 complete faction verticals
8. Build 10–15 recurring NPCs
9. Build 6 major stations
10. Build 20–30 secrets/discoveries

## Phase C — Quest density

11. Main story expansion
12. Faction chains
13. Character arcs
14. Local station stories
15. Exploration content
16. Cross-faction conflicts

## Phase D — Systemic polish

17. Replay divergence
18. world response
19. information contradictions
20. balance
21. content QA
22. mobile performance

## First milestone

Do not target "Morrowind scale".

Target:

> **One sector that feels like a complete RPG world.**

If one sector is convincing, scale horizontally.
