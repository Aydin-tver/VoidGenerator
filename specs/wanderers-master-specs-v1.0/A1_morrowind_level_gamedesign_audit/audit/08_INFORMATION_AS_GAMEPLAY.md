# 08 — Information as Gameplay

This should become one of Wanderers' signature systems.

The player maintains a knowledge state:

```text
KNOWN
SUSPECTED
RUMORED
CONFIRMED
DISPROVEN
CONTRADICTED
UNKNOWN
```

## Example

```text
Tidari says:
"Route was changed by OmniCorp."

Registry:
"No valid OmniCorp signature."

Nova:
"Pattern matches Ferrum anomaly."

Player conclusion:
"Someone is imitating OmniCorp routing."
```

The game should not automatically display the conclusion.

The player discovers it.

## Benefits

This supports:
- detective gameplay;
- faction politics;
- lore;
- replayability;
- non-linear navigation;
- secrets;
- player agency.
