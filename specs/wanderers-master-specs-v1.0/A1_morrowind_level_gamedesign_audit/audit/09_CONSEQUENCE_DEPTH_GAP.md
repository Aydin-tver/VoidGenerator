# 09 — Consequence Depth Gap

A flag alone is not a consequence.

Weak:

```text
story_flag = reported
```

Strong:

```text
reported
 ↓
Tidari trusts player
 ↓
Tidari provides restricted record later
 ↓
Free Merchants hear player cooperated
 ↓
another faction distrusts player
 ↓
a later mission changes
 ↓
a new evidence path opens
```

## Consequence levels

L1 — dialogue variation
L2 — mission availability
L3 — reward/access change
L4 — NPC relationship
L5 — faction relationship
L6 — station/world state
L7 — main-story branch context
L8 — ending/endgame state

Target: major choices should reach at least L3–L5.
Major faction choices should occasionally reach L6–L8.
