# 14 — Biggest Gaps

## Critical

1. Factions are not yet gameplay systems.
2. World reactivity is not yet dense enough.
3. Exploration lacks enough discovery content.
4. NPC memory network is too small.
5. Consequences need multi-step propagation.
6. Quest variety is insufficient.
7. Player self-directed goals are insufficient.
8. Build/equipment has insufficient narrative impact.

## High

9. Information system needs to become a central gameplay loop.
10. Station identities need more local stories.
11. Secrets need much greater density.
12. Replay paths need more divergence.
13. Environmental storytelling needs expansion.

## Medium

14. More ambient dialogue.
15. More lore artifacts.
16. More optional rewards.
