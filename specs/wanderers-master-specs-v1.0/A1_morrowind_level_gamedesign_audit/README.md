# Wanderers — Morrowind-Level Game Design Audit v1.0

## Executive conclusion

Wanderers has a strong narrative architecture but is **not yet at Morrowind-level RPG depth as a playable game**.

The main gap is not lore documentation. It is **interactive density**:
the number of meaningful relationships between player actions, information,
factions, characters, gameplay systems, locations, rewards and future consequences.

Morrowind's relevant strength was not simply volume of text. Its quests,
factions, exploration and world information formed a network in which learning
about the world itself became a gameplay resource. citeturn0search22turn0search26

This audit therefore evaluates the player experience, not document count.
