# 20-Hour Player Experience Target

A player should be able to spend ~20 hours without simply following the main
story.

Possible experience:

```text
Hour 1–2
Arrival
Convoy
First faction contacts
First anomaly

Hour 3–5
Trade
Station relationships
Rumors
First optional discovery

Hour 6–8
Faction choice
Contradictory evidence
Equipment-based opportunity

Hour 9–12
Character arc
Faction conflict
Hidden location
Consequences become visible

Hour 13–16
Multiple investigations
World response
Alliance/rivalry
Major revelation

Hour 17–20
Main story continuation
Personal identity discovery
Faction consequences
Choice that determines future trajectory
```

The exact pacing can change. The important requirement is that the player is
creating their own path through interconnected content.
