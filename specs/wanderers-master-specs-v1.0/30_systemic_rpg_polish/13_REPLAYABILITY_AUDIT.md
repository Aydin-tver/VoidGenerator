# Replayability Audit v1.0

Run multiple simulated playthrough profiles.

## Run A
Independent trader.

## Run B
OmniCorp-aligned operator.

## Run C
Free Merchant-aligned smuggler.

## Run D
Exploration-heavy investigator.

## Run E
Covert information broker.

Compare:

- missions;
- evidence;
- NPC relationships;
- faction states;
- economic state;
- discoveries;
- equipment;
- ending context.

Target:
At least 30% of major story situations should have materially different context between two strong playthroughs.
