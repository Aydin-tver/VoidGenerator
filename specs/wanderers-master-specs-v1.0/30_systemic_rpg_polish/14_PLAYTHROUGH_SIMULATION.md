# Playthrough Simulation Protocol v1.0

Each test run should record:

```yaml
run:
  build:
  faction_strategy:
  economic_strategy:
  exploration_strategy:
  main_story_path:
  major_choices:
  failures:
  discoveries:
  relationships:
  equipment:
  ending:
```

## Minimum scenarios

1. Independent / low faction commitment.
2. Strong OmniCorp alignment.
3. Strong Free Merchant alignment.
4. Information-focused investigator.
5. Economic manipulator.
6. Exploration-focused player.
7. Failure-heavy playthrough.
8. Mixed hybrid build.

The goal is not to prove every run can finish.

The goal is to expose systemic convergence and dead systems.
