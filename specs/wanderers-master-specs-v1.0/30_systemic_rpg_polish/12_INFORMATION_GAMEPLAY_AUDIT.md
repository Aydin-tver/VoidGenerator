# Information Gameplay Audit v1.0

This is the signature system and receives the highest target.

Check:

- asymmetric knowledge;
- incomplete information;
- contradictory evidence;
- source reliability;
- interpretation;
- corroboration;
- information trading;
- concealment;
- misinformation;
- NPC beliefs.

## Critical test

Can two players reach different beliefs about the same event based on different evidence?

If yes, the system is working.

Target:
Information Gameplay >= 9/10.
