# Build Diversity Audit v1.0

Test at least these builds:

- Signal Investigator;
- Independent Trader;
- Broker;
- Smuggler;
- Salvager;
- Engineer;
- Scout;
- Faction Operative;
- Combat Specialist;
- Hybrid Wanderer.

Each must have unique opportunities, not merely different stats.

## Test

Give every build the same major problem.

Record:
- available information;
- available approaches;
- risk;
- cost;
- outcome;
- consequences.

If all builds converge to the same solution, build diversity is insufficient.
