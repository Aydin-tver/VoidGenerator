# Agency Audit v1.0

Check whether players can meaningfully choose:

- goals;
- approach;
- information strategy;
- preparation;
- capabilities;
- risk;
- faction relationship;
- economic strategy;
- identity;
- whether to pursue an objective at all.

## Audit questions

1. Can the player solve the problem in different ways?
2. Do different builds create different solutions?
3. Can the player refuse the intended objective?
4. Can failure create a new playable state?
5. Does the game remember meaningful choices?

Major mission target:
Agency Score >= 4.

Release target:
Average major-mission Agency Score >= 4.
