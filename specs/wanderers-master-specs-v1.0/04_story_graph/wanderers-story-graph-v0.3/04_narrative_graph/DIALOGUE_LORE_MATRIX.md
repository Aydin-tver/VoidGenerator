# Dialogue ↔ Lore Matrix v0.3

## Dialogue functions

| Type | Primary job | State impact |
|---|---|---|
| ambient | character/world texture | normally none |
| informational | transfer known information | knowledge/evidence optional |
| character | reveal personality/relationship | trust/memory if justified |
| investigative | expose clue | evidence / mystery |
| negotiation | resolve competing interests | faction/character consequence |
| conflict | force a position | story/faction consequence |
| revelation | reframe a mystery | evidence / story flag |
| resolution | close an arc | character/world consequence |

## Lore duplication rule
Two NPCs may communicate the same fact only when their perspectives differ or the repetition has a gameplay purpose. Otherwise, reuse the existing knowledge state and give the second NPC a new interpretation.

## Dialogue gate hierarchy
1. gameplay capability
2. story stage
3. evidence/knowledge
4. faction access
5. character relationship
6. world consequence

Gates must be explainable to the player through context; avoid arbitrary invisible requirements.
