# Wanderers of the Void — Main Story Rewrite v1.0

## Purpose

Rewrite the main campaign so it actively uses the systemic RPG architecture created in Stages 17–28.

The main story must no longer be a sequence of:
MISSION → DIALOGUE → NEXT MISSION.

Instead:

PLAYER INTENT
→ INFORMATION
→ PREPARATION
→ APPROACH
→ ACTION
→ RESULT
→ WORLD RESPONSE
→ NEW INFORMATION
→ NEW OPPORTUNITY
→ STORY PROGRESSION

## Core identity

The player is not a chosen hero.

The player is an emerging autonomous ship intelligence whose understanding of itself changes through:
- work;
- investigation;
- relationships;
- evidence;
- faction conflicts;
- exploration;
- equipment;
- choices;
- consequences.

The story's central mystery is not simply "what is the Void?"

It is:

> What happens when identity, memory and consciousness can exist across biological, artificial and Thread-based substrates?

The Voidari created the technology that makes this question dangerous.

## Narrative rule

The story must never require a specific player build when an equivalent systemic solution exists.

Different players can reach the same major revelation through different evidence paths.
