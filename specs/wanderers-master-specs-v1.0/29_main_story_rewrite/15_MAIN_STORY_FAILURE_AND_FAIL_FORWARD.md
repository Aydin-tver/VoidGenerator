# Main Story Failure & Fail-Forward v1.0

Main story failure should usually create a new situation.

Examples:

Failed investigation:
→ evidence lost
→ must find another source.

Failed negotiation:
→ faction distrust
→ alternative supplier.

Failed covert operation:
→ security increases
→ investigation becomes harder.

Failed combat:
→ cargo lost
→ NPC relationship changes
→ new recovery opportunity.

A failed action should change the story rather than simply reload the previous state.
