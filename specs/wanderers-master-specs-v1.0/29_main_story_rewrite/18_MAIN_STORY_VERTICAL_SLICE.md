# Stage 29 Vertical Slice — Rewritten Ferrum Arc

## Situation

A convoy route near Ferrum shows an unexplained correction.

The player does not receive a single mandatory investigation quest.

### Route 1 — Sensors
Detects anomalous telemetry.

### Route 2 — Commerce
Notices that the corrected route coincides with unusual component purchasing.

### Route 3 — Lena
Uses relationship/trust to hear convoy concerns.

### Route 4 — Tidari
Investigates registry inconsistencies.

### Route 5 — Nova
Uses engineering analysis on recovered hardware.

### Route 6 — Exploration
Finds an abandoned relay associated with the route.

### Route 7 — Faction
Uses faction access to obtain restricted records.

The player can combine routes.

Possible conclusions:
- routine corruption;
- deliberate manipulation;
- faction operation;
- unknown autonomous process.

No conclusion is automatically presented as truth.

The player's evidence set determines available interpretations.

## Consequence

The player chooses whether to:
- report;
- conceal;
- sell;
- investigate;
- exploit;
- protect an NPC;
- confront a faction.

That decision changes the next story situation.
