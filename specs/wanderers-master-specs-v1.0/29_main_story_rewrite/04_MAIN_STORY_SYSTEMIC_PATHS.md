# Main Story Systemic Paths v1.0

Major revelations should have multiple evidence routes.

## Example: SIGMA connection

Path A — Sensors
Deep scan reveals repeated signal pattern.

Path B — Engineering
Recovered hardware contains matching architecture.

Path C — NPC
Researcher provides partial technical testimony.

Path D — Faction
Restricted intelligence reveals historical project data.

Path E — Exploration
Hidden relay contains corrupted SIGMA fragment.

Path F — Economy
Repeated procurement patterns reveal unusual component demand.

The player can discover several or only some paths.

No single mandatory clue should be the only way forward unless it is intentionally a late-stage reveal.
