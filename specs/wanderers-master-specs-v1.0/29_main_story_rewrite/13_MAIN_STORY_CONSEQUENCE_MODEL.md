# Main Story Consequence Model v1.0

Major choices create consequences at multiple horizons.

Immediate:
- dialogue;
- reward;
- relationship;
- mission outcome.

Medium:
- faction access;
- economic state;
- NPC behavior;
- route/security changes.

Long:
- faction strategy;
- world-state transition;
- final act conditions;
- ending context.

Avoid binary:
GOOD END / BAD END.

Instead create different world states and interpretations.
