# Acceptance

The slice passes only if a tester can:

- complete REPORT and WITHHOLD trajectories;
- see different later dialogue;
- observe changed faction state;
- observe changed NPC memory;
- observe changed station context;
- discover optional scan evidence;
- save/load without losing state;
- replay without duplicate consequences;
- complete without GPS;
- continue after either major choice.

Failure of any of these is an integration defect, not a content polish issue.
