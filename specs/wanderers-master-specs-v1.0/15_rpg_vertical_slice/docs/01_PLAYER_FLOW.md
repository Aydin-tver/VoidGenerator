# Player Flow

## Path A — Report

1. Meet Lena.
2. Detect convoy irregularity.
3. Reach Solaris.
4. Receive Tidari registry information.
5. Report the unsigned route amendment.
6. Tidari trust increases.
7. OmniCorp context becomes suspicious.
8. Ferrum anomaly investigation opens.
9. Return to Solaris.
10. Lena/Tidari dialogue reflects the choice.
11. New evidence becomes available.

## Path B — Withhold

1–4 identical.
5. Withhold evidence.
6. Lena trust remains higher than Tidari trust.
7. A Free Merchant information path opens.
8. Ferrum investigation begins from a different interpretation.
9. Return context differs.

## Path C — Capability discovery

A sufficiently capable scanner reveals an additional structural match at
Ferrum. This adds evidence but does not automatically reveal its meaning.

No path requires a quest marker.
