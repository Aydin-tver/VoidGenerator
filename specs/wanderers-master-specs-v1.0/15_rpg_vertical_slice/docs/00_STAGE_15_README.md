# Stage 15 — RPG Vertical Slice v1.0

This stage turns Stage 14 into one integrated playable narrative slice.

## Scenario

MSR-01 Convoy Irregularity
→ MSR-02 Registry Report
→ player choice: REPORT / WITHHOLD
→ optional capability discovery
→ MSR-03 Ferrum Anomaly
→ faction pressure
→ return to Solaris
→ changed NPC/station context
→ next lead

## Demonstrated systems

- Information / Knowledge
- Faction Progression
- NPC Memory
- Consequence Propagation
- World / Station Reactivity
- Equipment → Narrative Capability

## Design goal

The player should be able to understand the situation from fragments and make
a decision without a GPS arrow.

This package is a runtime-ready candidate slice, not a claim that the current
Wanderers branch already executes every adapter contract.
