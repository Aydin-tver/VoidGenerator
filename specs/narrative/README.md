# Wanderers — Narrative Canon

Творческий канон игры (лор, граф истории, миссии, референсы). Извлечено из `wanderers-master-specs-v1.0/A2_story_specs_release_1_7` при аудите (см. `../AUDIT_v1.0.md`).

**Важно:** системные решения определяются только `../master spec.md` (v2.0). Этот каталог — контент (что рассказываем), а не архитектура (как реализуем). При адаптации миссий под v2.0 использовать JSON-схемы из master spec §16.

## Состав
- `01_lore/` — канон, лор-библия, терминология, граф истории, инвентарь миссий.
- `GAMEPLAY_LOOP.md` — контракт игровой петли, journey events, вертикальный срез 15 мин.
- `05_story_examples/` — репрезентативные narrative units как шаблоны.
- `BACKLOG.md` — открытые проблемы графа и контентные пустоты.
- `VOICE_GUIDE.md` — голоса архетипов, banned phrases, контроль одинаковости AI-батчей.

1. `01_lore/LORE_CANON.md` + `LORE_BIBLE.md` + `TERMINOLOGY.md`
2. `01_lore/STORY_GRAPH.md`

4. `GAMEPLAY_LOOP.md`
